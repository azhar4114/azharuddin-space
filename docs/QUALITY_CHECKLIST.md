# Quality and Launch Checklist

## Content accuracy
- [ ] Name and preferred public identity confirmed.
- [ ] Employment dates checked against current resume.
- [ ] Job titles and employer/client labels verified.
- [ ] Certifications and education verified.
- [ ] Technical skill levels reviewed.
- [ ] Project ownership and public status confirmed.
- [ ] Quantitative claims supported by evidence.
- [ ] No confidential client/employer information.
- [ ] Resume PDF is current and approved.
- [ ] Email, LinkedIn and GitHub URLs verified.

## UX and design
- [ ] Dark professional visual system is consistent.
- [ ] Homepage proposition is clear within a few seconds.
- [ ] Recruiter can find resume and experience quickly.
- [ ] Developer can find writing and tools quickly.
- [ ] Potential client can understand services and contact path.
- [ ] Mobile menu works by keyboard and touch.
- [ ] No horizontal overflow.
- [ ] Reduced-motion preference respected.
- [ ] Focus states visible.
- [ ] Contrast is sufficient.

## Functionality
- [ ] Every CTA works.
- [ ] No dead buttons.
- [ ] Project links are correct.
- [ ] Resume download works.
- [ ] Article pages render correctly.
- [ ] Tool input validation works.
- [ ] Tools process data locally.
- [ ] Contact flow is real or clearly an email link.
- [ ] External links open safely.

## SEO
- [ ] Unique page titles.
- [ ] Meta descriptions.
- [ ] Canonical URLs.
- [ ] Sitemap.
- [ ] robots.txt.
- [ ] Open Graph image and metadata.
- [ ] Structured data is accurate.
- [ ] No draft content indexed.
- [ ] Social sharing preview checked.

## Engineering
- [ ] Clean install works.
- [ ] Development server works.
- [ ] Production build succeeds.
- [ ] Type checks pass.
- [ ] Lint/format checks pass where configured.
- [ ] No console errors.
- [ ] No exposed secrets.
- [ ] Dependencies are justified.
- [ ] README explains editing and deployment.

## Launch
- [ ] Preview deployment reviewed.
- [ ] Custom domain connected.
- [ ] HTTPS verified.
- [ ] DNS records reviewed before changes.
- [ ] Existing email DNS records preserved.
- [ ] Analytics/privacy behaviour documented.
- [ ] Latest resume deployed.
- [ ] LinkedIn profile links to website.
