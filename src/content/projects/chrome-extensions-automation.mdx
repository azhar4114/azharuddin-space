> **Sanitised Enterprise Study:** An engineering overview of a suite of browser extensions, internal web applications, and automation tools built to solve operational bottlenecks for network operations and field deployment teams at Astreya (supporting tier-1 enterprise operations on the Google account). All proprietary client configurations and internal identifiers are generalised or omitted.

---

## 1. Overview

In large enterprise operations, engineers and provisioning teams frequently switch between multiple disparate web tools, ticketing queues, and legacy databases. This manual context-switching slows operational velocity and introduces data entry errors.

Over multiple years, Mohammad Azharuddin architected, engineered, and maintained an interconnected productivity suite comprising custom browser extensions, serverless backend pipelines, operational chatbots, and mobile utilities that eliminated repetitive manual overhead.

---

## 2. Problem or Motivation

Enterprise operations faced several friction points across daily workflows:
- **Low Feedback Engagement:** Gathering post-project customer satisfaction (CSAT) ratings via external survey portals suffered from low response rates due to cumbersome multi-click login flows.
- **Manual Data Cross-Referencing:** Network provisioners had to manually cross-reference circuit IDs, installation dates, and acceptance milestones across separate legacy portals.
- **Search Latency & Ticket Tracking:** Finding active operational tickets required querying multiple unindexed databases without unified caching.
- **Field Reporting Delays:** Technicians deploying physical infrastructure on-site had limited access to desktop tools, creating delays in logging work completions.

---

## 3. Project Objectives

- Build non-invasive browser extensions that inject automation directly into operational web portals without requiring backend overhauls.
- Automate CSAT survey collection by embedding feedback mechanisms directly into weekly email summaries and operational dashboards.
- Provide unified multi-field search with client-side caching to reduce load on underlying databases.
- Develop lightweight mobile utilities for field technicians to record milestone completions on-site.
- Create automated conversational chatbots to handle recurring support inquiries.

## 6. Technical Implementation

### A. Automated Customer Satisfaction (CSAT) System
- Engineered an automated pipeline that sent weekly summary emails for completed milestones, allowing internal stakeholders to submit ratings directly from within their email client.
- Built a companion Chrome extension that injected interactive rating overlays into operational portals.
- Streamed responses through Google Apps Script into Google BigQuery for real-time executive dashboard reporting.

### B. Netco Circuit Synchronization Extension
- Developed a browser extension with an AngularJS interface that dynamically parsed open project pages and unified circuit statuses.
- Built a bulk-edit interface enabling provisioners to batch-update installation and acceptance dates across multiple circuits in a single action.
- Configured daily delta synchronization to cloud storage buckets using service account credentials.

### C. Advanced Multi-Field Ticket Search
- Created a search utility supporting concurrent queries across 22 operational ticket fields with a 10-minute client-side TTL cache.
- Built automated ticket escalation logic that flagged unresolved tickets after 48 hours and notified leads automatically.

### D. MFS Field Deployment Mobile Tool
- Built a companion native Android application for field technicians, enabling ticket lookups, work duration logging, and completion code reporting on site.

### E. Operational Support Chatbot
- Developed an interactive chatbot using Google Apps Script and Dialogflow natural language processing to resolve recurring operational queries automatically.

---

## 7. Key Engineering Decisions

- **Client-Side DOM Injection over Full Rewrites:** Choosing to inject browser extension overlays rather than waiting for multi-quarter backend rebuilds allowed delivering functional automation in days.
- **Client-Side Caching (TTL):** Implementing local storage caching for frequent lookup queries prevented redundant calls to backend operational ticket databases.
- **Serverless Cloud Backends:** Leveraging Google Apps Script paired with BigQuery allowed rapid deployment with zero dedicated virtual machine maintenance.

---

## 8. Challenges and Solutions

| Challenge | Engineering Solution |
|---|---|
| **Chrome Manifest v3 Service Worker Lifecycles** | Migrated persistent background pages to ephemeral event-driven service workers, storing session state in `chrome.storage.local`. |
| **Cross-Origin Portal Constraints** | Configured declarative net request rules and authorized host permissions to handle multi-domain API handshakes securely. |
| **DOM Volatility Across Legacy Portal Updates** | Used resilient CSS selector hierarchies and MutationObservers to ensure extensions attached reliably even during dynamic page updates. |
